# 解锁流程

欢迎页输入密码后，`Welcome.vue` 的 `enter` 调用 `unlock`。`unlock` 先用 `openVault` 解开助记词，再走 `enter`。这次没有密码参数，所以不会再次 `sealVault`。

## openVault

```mermaid
flowchart TD
  pwd[输入的密码] --> read["读取 localStorage：aegis.vault.v1"]
  read --> exists{信封存在}
  exists -->|否| missing["抛错：这台浏览器里还没有钱包"]
  exists -->|是| parse["解析 JSON：盐、IV、密文、迭代次数"]
  parse --> kdf["deriveKey：PBKDF2-SHA256"]
  kdf --> aes["AES-GCM 解密"]
  aes --> tag{认证标签通过}
  tag -->|否| bad["抛错：密码不对，或者本机保险库已经损坏"]
  tag -->|是| secret["得到助记词和账户名"]
```

密钥不是从保险库里读出来的。`deriveKey` 用这次输入的密码，配上信封里保存的盐和迭代次数，重新算一把 256 位 AES-GCM 密钥：

```mermaid
flowchart LR
  password[密码的 UTF-8 字节] --> base[导入为 PBKDF2 原料密钥]
  salt[信封里的 16 字节盐] --> stretch["HMAC-SHA256 重复信封中的次数"]
  base --> stretch
  stretch --> key[256 位 AES-GCM 密钥]
```

解密使用信封里的 12 字节 IV 和密文。密文末尾的认证标签同时检查密码和数据。密码错、密文被改过，都会在这一步失败，函数不区分这两种原因。

通过之后，明文是 UTF-8 的 `{ mnemonic, label }`。`unlock` 把这两个值交给 `enter`：拉取 `/api/v1/meta`、派生五条链地址、同步账户，然后写入 `wallet.session`。
