# 各种链测试环境水龙头

地址从资产页复制。当前 `aegis.network=testnet`，各链对应的网络是：

| 链 | 测试网 | 资产页上的地址 |
|---|---|---|
| Bitcoin | Testnet3 | `tb1q` 开头 |
| Ethereum | Sepolia | `0x` 开头，和 BNB 是同一个地址 |
| BNB | BSC Testnet | 同上 |
| Solana | Devnet | Base58 公钥 |
| TRON | Shasta | `T` 开头 |

Testnet4、Nile、主网的币进不了这套配置。

## Bitcoin Testnet3

原生币是 tBTC。应用读的是 `https://mempool.space/testnet/api`，到账看 [mempool.space/testnet](https://mempool.space/testnet)。

| 领什么 | 水龙头 | 说明 |
|---|---|---|
| tBTC | [faucet.satloot.com/en](https://faucet.satloot.com/en/) | 接受 `tb1q`。每次约 0.00010000 tBTC，浏览器里做一小段运算。每个地址和 IP 大约一天一次 |

[bitcoinfaucet.uo1.net](https://bitcoinfaucet.uo1.net/) 和 [coinfaucet.eu/en/btc-testnet](https://coinfaucet.eu/en/btc-testnet/) 不收 `tb1q`。Testnet4 的币和这里不是同一本账。

## Ethereum Sepolia

原生币是 Sepolia ETH，用来付 gas。稳定币是另外领的。

| 领什么 | 水龙头 | 合约 | 说明 |
|---|---|---|---|
| ETH | [sepolia-faucet.pk910.de](https://sepolia-faucet.pk910.de/) | 无 | 浏览器运算，不用主网 ETH |
| ETH | [cloud.google.com/application/web3/faucet](https://cloud.google.com/application/web3/faucet) | 无 | 要登录 Google 账号 |
| USDC | [faucet.circle.com](https://faucet.circle.com/) | `0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238` | 选 Ethereum Sepolia。大约每 2 小时、每个地址 20 USDC |
| USDT | 没有对上这个合约的公开水龙头 | `0xaA8E23Fb1079EA71e0a56F48a2aA51851D8433D0` | 6 位小数。别人转来这张合约上的币，资产页才会大于 0 |

到账看 [sepolia.etherscan.io](https://sepolia.etherscan.io)。

## BSC Testnet

原生币是 tBNB。USDT 是 18 位小数，和以太坊上的 6 位不是同一个单位。

| 领什么 | 水龙头 | 合约 | 说明 |
|---|---|---|---|
| tBNB、USDT | [bnbchain.org/en/testnet-faucet](https://www.bnbchain.org/en/testnet-faucet) | USDT `0x337610d27c682E347C9cD60BD4b3b107C9d34dDd` | 官方水龙头。页面要求地址在 BSC 主网上至少有 0.002 BNB。大约 24 小时一次 |
| USDC | 应用没配测试网合约 | 无 | 资产页余额保持 0，转账会被拒绝 |

领到 USDT 后，在 [testnet.bscscan.com](https://testnet.bscscan.com) 上看合约是不是上面这一张。合约不同，应用查不到。

## Solana Devnet

原生币是 devnet SOL。USDC 用 Circle 的 devnet mint。

| 领什么 | 水龙头 | 合约 | 说明 |
|---|---|---|---|
| SOL | [faucet.solana.com](https://faucet.solana.com/) | 无 | 选 Devnet。登录 GitHub 后额度更高。大约 8 小时 2 次 |
| USDC | [faucet.circle.com](https://faucet.circle.com/) | `4zMMC9srt5Ri5X14GAgXhaHii3GnPAEERYPJgZJDncDU` | 选 Solana Devnet |
| USDT | 应用没配测试网 mint | 无 | 资产页余额保持 0，转账会被拒绝 |

命令行也可以领 SOL：

```text
solana airdrop 2 你的地址 --url devnet
```

转 USDC 时，对方还没有这个币的关联账户，交易里会先创建，大约再花 0.00204 SOL。手续费另付 0.000005 SOL。

## TRON Shasta

地址要先收到 TRX，账户才激活。没激活就转账，节点会报 `no OwnerAccount`。

| 领什么 | 水龙头 | 合约 | 说明 |
|---|---|---|---|
| TRX、USDT | [shasta.tronex.io/join/getJoinPage](https://shasta.tronex.io/join/getJoinPage) | USDT `TG3XXyExBkPp9nzdajDZsozEu4BkaSJozs` | 上面一栏是 TRX，大约 2000。下面一栏是测试 USDT，大约 1000。每个地址和 IP 大约一天一次 |
| USDC | 应用没配 Shasta 合约 | 无 | 资产页余额保持 0，转账会被拒绝 |

`T9yD14Nj9j7xAB4dbGeiX9h8unkKHxuWwb` 是 20 个 0 的写法，不能当收款地址。Nile 的币进不了 Shasta。到账看 [shasta.tronscan.org](https://shasta.tronscan.org)。

## 本地结算链

结算页的「领取测试 ETH 和 USDC」打的是本机 Hardhat，链编号 31337。那是结算用的 MockUSDC，和上面 Sepolia、BSC 的币不是同一笔。Hardhat 重启后，这些币会清空，需要重新领取。
